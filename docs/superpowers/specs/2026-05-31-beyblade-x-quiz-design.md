# BEYBLADE X Quiz Design

## Goal

小学生がスマホのブラウザで遊べる、BEYBLADE Xのパーツ画像4択クイズをローカルで起動できるようにする。

## Scope

- 公式タカラトミーサイトのBEYBLADE X製品ページにあるブレード画像を使う。
- クイズ対象はブレード、ラチェット、ビットにする。ランチャー画像は問題にしない。
- 1チャレンジは間違えるまで続く。正解するたびに連続正解数を加算する。
- 1問の回答制限時間は10秒。時間切れは不正解として扱い、正解を表示して次へ進める。
- 不正解または時間切れになったらゲームオーバーにして、連続正解数を記録として表示する。
- 端末内ランキングをタイトル画面に表示する。1位記録になった場合だけ名前入力フォームを出し、ブラウザの `localStorage` に保存する。
- 選択肢は4択。ブレード問題ではブレード名、ラチェット問題ではラチェット名、ビット問題ではビット名のみを表示する。
- 難しめの漢字はUI上で `<ruby>` によるふりがなを付ける。
- まずはローカルで触れる静的Webアプリとして作る。デプロイは対象外。

## Data

初期データはタカラトミー公式のラインアップ画像をベースに、ブレード35件、ラチェット11件、ビット12件を使う。

- BX: ドランソード、ヘルズサイズ、ウィザードアロー、ナイトシールド、ナイトランス、レオンクロー、ライノホーン、フェニックスウイング、ユニコーンスティング、ヴァイスタイガー、コバルトドラグーン、クリムゾンガルーダ、トリケラプレス、サムライカリバー、ドランストライク
- UX: ドランバスター、ヘルズハンマー、ウィザードロッド、レオンクレスト、シルバーウルフ、サムライセイバー、インパクトドレイク、スコーピオスピア、メテオドラグーン、バレットグリフォン
- CX: ドランブレイブ、ウィザードアーク、ペルセウスダーク、ペガサスブラスト、ソルエクリプス、ウルフハント、フェニックスフレア、バハムートブリッツ、ナイトフォートレス、ラグナレイジ

画像URLは各製品ページのパーツスライドを使う。ブレードは `_image/<CODE>_01@1.png`、ラチェットは `_image/<CODE>_03@1.png`、ビットは `_image/<CODE>_04@1.png` を使う。ランチャー画像は使わない。

## UX

スマホの縦画面を主対象にする。1画面に「連続正解数」「10秒タイマー」「パーツ画像」「4つの回答ボタン」「正誤フィードバック」「次へ/記録へ」を収める。タップしやすいように回答ボタンは広めにし、画像は公式サイト風の黒背景、斜めライン、シアン/レッドの発光エフェクトで中央表示する。正解時はリング、光線、Xスパーク、正解ボタン発光、画像ポップで嬉しさが伝わる演出を入れる。

スタート画面では「BEYBLADE X / QUIZ」を主役にしたロゴ型タイトル、間違えるまでのモード説明、10秒制限、ランキングTOP5を表示する。全体の色は黒、白、金属感、シアンを中心にし、赤・黄・緑は不正解、残り時間、正解などの状態表現に限定して使う。結果画面ではGAME OVER/NEW RECORD、連続正解数、名前入力フォームまたはランキング、もう一回ボタンを出す。

## Architecture

- `src/beyblades.js`: クイズ対象データ。カテゴリ、名前、画像URL、公式ページURL、ラインを持つ。
- `src/quizEngine.js`: 出題生成、選択肢生成、採点、合否判定。DOMに依存しない。
- `src/ranking.js`: 端末内ランキングの読み込み、保存、入力値の正規化、1位判定。
- `src/app.js`: DOMイベント、画面描画、画像読み込みエラー表示。
- `src/styles.css`: スマホ優先の見た目と状態スタイル。
- `test/quizEngine.test.mjs`: Node標準テストでゲーム進行を検証する。

## Error Handling

画像が読み込めない場合は、問題を壊さずに「画像を読みこめません」と出し、選択肢で回答できる状態は保つ。データが10件未満、または4択を作れない場合は、ゲーム開始時に画面上へエラーを出す。

## Testing

Node標準の `node:test` で純粋ロジックを確認する。

- 10問が重複なしで作られる。
- 混合クイズの10問にはブレード、ラチェット、ビットが必ず含まれる。
- ストリークモードは固定の最終問題数を持たず、正解後に次の問題へ進み、不正解や時間切れで終了する。
- ランキングはスコア順に整列し、名前を短く正規化してTOP5だけ保存する。
- 各問の4択に正解が1つだけ含まれ、選択肢は同じカテゴリだけで構成される。
- 7点以上でクリア、6点以下で未クリアになる。
- 回答後にスコアと状態が更新され、同じ問題を二重採点しない。
- 表示用の選択肢ラベルは、組み合わせ名ではなくパーツ単体名になる。
- 時間切れは不正解として記録され、スコアは増えない。
- 画像データがブレード、ラチェット、ビットの公式パーツ画像URLだけを使っている。
